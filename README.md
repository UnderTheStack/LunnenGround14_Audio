# LunnenGround14_Audio

# Исправление звука на Lunnen Ground 14 в Linux

В дистрибутивах Linux на ноутбуках Lunnen Ground 14 (плата LL4FA-02) звук через наушники работает «из коробки», а встроенные динамики молчат.

**Причина**: Нестандартная заводская разводка. Ядро по умолчанию отправляет звук на контакт 0x14, который является пустышкой, тогда как реальные динамики припаяны к контакту 0x1b.

## Решение
Необходимо программно перенаправить аудиопоток. Для этого установите пакет ***alsa-tools*** (через pacman для Arch или apt для Ubuntu/Mint) и запустите графическую утилиту от имени администратора:
Нам нужно программно отключить нерабочий контакт и перенаправить звук на правильный. Это делается в несколько кликов через официальную утилиту ALSA.
### Шаг 1: Установка программы

Откройте терминал и установите пакет alsa-tools.

#### Для Arch Linux и производных:
```Bash
sudo pacman -S alsa-tools
```
#### Для Ubuntu / Linux Mint / Debian:
```Bash
sudo apt install alsa-tools-gui
```
### Шаг 2: Переназначение контактов

Запустите графическую утилиту от имени суперпользователя:
```Bash
sudo hdajackretask
```

В открывшемся окне программы выполните следующие действия:

- В самом верху в меню Select a codec выберите ваш звуковой чип — ***Realtek ALC269VC***.

- В правом меню ***Options*** поставьте галочку ***Show unconnected pins*** (Показать неподключенные контакты).

- Найдите блок Pin ID: ***0x14***. Поставьте под ним галочку ***Override*** (Переопределить) и в выпадающем меню строго выберите пункт ***Not connected*** (Не подключено).

- Найдите блок Pin ID: ***0x1b***. Поставьте галочку ***Override*** и выберите пункт ***Internal speaker*** (Внутренний динамик).

- В правом нижнем углу нажмите кнопку ***Install boot override*** (Применять настройки при каждой загрузке).

### Шаг 3: Перезагрузка

Программа сгенерирует правильный конфигурационный файл для звуковой подсистемы.
Теперь просто закройте утилиту и полностью перезагрузите ноутбук:
```Bash
reboot
```
Готово! После запуска системы звук из встроенных динамиков будет работать штатно, а стандартные ползунки громкости будут управлять им корректно.
